# Portal Web Institucional y Panel Administrativo - I.E. N° 82115 "José Faustino Sánchez Carrión"

Página web informativa oficial y sistema de gestión administrativa para la **Institución Educativa N° 82115 "José Faustino Sánchez Carrión"** de **Huamachuco** (UGEL Sánchez Carrión - DRE La Libertad).

## Características Principales
- **Diseño 100% Responsivo**: Desarrollado con HTML5, Tailwind CSS, FontAwesome 6, Lucide Icons y JavaScript moderno.
- **Secciones Institucionales**:
  - Barra superior institucional con Pop-up de **Comunicado Oficial de Dirección**.
  - Header pegajoso con la insignia oficial (`img/logo.png`).
  - Portada Hero en homenaje al Tribuno de la República **José Faustino Sánchez Carrión**.
  - Estadísticas dinámicas y vacantes en tiempo real para **Inicial, Primaria y Secundaria**.
  - Galería escolar filtrable por categorías (*Cívico Huamachuco, Concursos Académicos, Aniversario, Deportes*).
  - Mesa de Partes Virtual, ubicación en **Av. 10 de Julio 281, Huamachuco** y botón directo de **WhatsApp**.
- **Panel Administrativo (`admin.html`)**:
  - Conectado a **SQL Server 2022 (`DB_IE82115_JFSC`)** en modo local y compatible con **GitHub Pages**.
  - Subida directa de fotografías desde PC o celular hacia `img/eventos/`.

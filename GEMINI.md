# Reglas Globales de Desarrollo

1. **Idioma**: Responde siempre en español y comenta todo el código en español.
2. **Autoría**: En todos los encabezados, firmas de código o pies de página de desarrollador, usa exactamente la etiqueta `Autor: César Quiroz` (nunca uses `Ing.`).
3. **Interfaces Web**: Cuando crees interfaces web, prioriza diseños modernos, responsivos, limpios y bien estructurados (usando HTML5, Tailwind CSS o Bootstrap y JavaScript moderno).
